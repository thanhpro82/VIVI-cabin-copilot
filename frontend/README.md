# VIVI Cabin Copilot — Frontend

Next.js (App Router, TypeScript, Tailwind v4) cho 2 màn hình người dùng của **VIVI Cabin Copilot** (AI20K Build Phase, team P-192): `/login`, `/driver` (IVI Screen tài xế + mô phỏng xe 3D), `/engineer` (Dashboard kỹ sư).

**Đọc `CLAUDE.md` trước khi sửa code** — trỏ tới `docs/ARCHITECTURE.md`, `docs/DESIGN_TOKENS.md`, `docs/CODING_STANDARDS.md` theo đúng thứ tự cần đọc.

## Chạy dev

```bash
npm install
npm run dev
```

Mở [http://localhost:3000](http://localhost:3000).

```bash
npm run build   # production build
npm run lint     # eslint
```
