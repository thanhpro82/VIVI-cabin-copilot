# PoC voice corpus

`manifest.jsonl` currently holds a **synthetic** corpus: 24 entries generated by
`scripts/synthesize_domain_audio.py` from Piper TTS (a single voice), each tagged
`speaker_code: "piper-tts-synthetic"` and `noise_condition: "synthetic-tts"` so
nobody downstream mistakes a run over it for a human-speaker measurement. The
sentence list lives in `RECORDING_CHECKLIST.md`.

Real, consent-cleared human recordings can replace individual entries later —
matched by `audio_id`, following the same schema below, with no code changes,
since `scripts/eval_stt_compare.py` only reads the manifest.

Each line is one JSON object per WAV file with these required fields:

```json
{"audio_id":"audio-ctrl-002","path":"ctrl-002.wav","reference_text":"Đặt điều hòa 24 độ","speaker_code":"spk-01","region":"north","noise_condition":"cabin-idle","duration_ms":1800,"consent_scope":"internal-poc-evaluation"}
```

Rules:

- `path` is relative to this directory and must resolve to an existing WAV file.
- `speaker_code` must be pseudonymous; do not store names or contact information.
- `consent_scope` must explicitly permit the intended benchmark and demo usage.
- Keep Vietnamese diacritics in `reference_text`; WER/CER normalizes Unicode NFC
  but does not transliterate or strip accents.
- Do not commit raw audio unless the team's repository policy and consent permit it.
