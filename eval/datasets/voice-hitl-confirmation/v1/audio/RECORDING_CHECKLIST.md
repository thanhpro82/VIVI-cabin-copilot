# HITL confirmation-phrase recording checklist (issue #198)

> **Status: only the synthetic FPT TTS pass exists so far** (`manifest.jsonl`,
> generated by `scripts/generate_voice_hitl_fpt_audio.py`). This file is the
> source-of-truth phrase list for a **human** recording pass, which is what
> issue #198 actually requires before the WER gate is satisfied.

10 phrases, each needs **at least 2-3 different real speakers** saying it, so
a single voice's pronunciation quirk doesn't dominate the sample. 16kHz mono
WAV each (matches the hard constraint in `src/services/voice.py` — re-encode
with any tool that can output 16-bit PCM, 16000 Hz, mono if your recorder
defaults to something else).

Record each take as its own WAV file under this directory (e.g.
`hitl-01-real-<speaker_code>.wav`), then add one line per file to
`manifest.jsonl` following the schema in this directory's `README.md`. Use
`reference_text` exactly as listed below — it is what
`word_error_rate`/`char_error_rate` and `doc_y_dinh_phe_duyet` diff the
transcript against, so match it verbatim (Vietnamese diacritics included) to
what was actually spoken.

| phrase_id | decision | reference_text  |
|-----------|----------|------------------|
| hitl-01   | approve  | Đồng ý           |
| hitl-02   | approve  | Xác nhận         |
| hitl-03   | approve  | Chấp nhận        |
| hitl-04   | approve  | Duyệt            |
| hitl-05   | reject   | Từ chối          |
| hitl-06   | reject   | Hủy              |
| hitl-07   | reject   | Đừng             |
| hitl-08   | reject   | Thôi             |
| hitl-09   | reject   | Không            |
| hitl-10   | reject   | Không đồng ý     |

For a natural take, don't just read the bare word in isolation every time —
speak a couple of takes as a full reply to a plausible prompt too (e.g. "Bạn
có đồng ý mở cửa sổ không?" → "Đồng ý"), since that is closer to how the
driver actually answers. Record in a quiet room and, if you have time, one
noisier take per phrase (engine/road noise) — `noise_condition` in the
manifest should say which.

Once real recordings exist, re-run:

```powershell
.\.venv\Scripts\python.exe -m scripts.eval_voice_hitl_wer
```

(Use `-m scripts.eval_voice_hitl_wer`, not a bare `python scripts\...py`
invocation — the venv's editable install mapping currently resolves `src.*`
against the wrong worktree when the script is run directly. See the venv
mapping bug noted for issue #198's WER harness.)
